# droit-verif-hallucination-ia

Vérifie les citations de jurisprudence d'un texte juridique français : chaque décision
citée existe-t-elle, et à la date indiquée ?

Les IA inventent des décisions, ou citent une vraie décision avec une fausse date. Des
tribunaux l'ont relevé dans des conclusions d'avocats (TJ Périgueux, 18 décembre 2025).
Ce programme interroge les bases officielles (Judilibre, Légifrance, ArianeWeb) et rend un
rapport. Il ne contient aucune IA : il ne peut rien inventer.

Il ne dit pas si la décision soutient l'argument. Ça reste le travail de l'avocat.

## État

En construction. Pas encore d'exécutable à télécharger.

## Ce qu'il faut

Un compte PISTE, gratuit, pour interroger Judilibre et Légifrance. Vos clés restent sur
votre ordinateur. Seuls le numéro et la date de chaque décision partent vers les bases
publiques, jamais votre texte.

## Installer

- **Windows** : l'installeur sera publié dans les *Releases* de ce dépôt.
- **Mac** : pas d'installeur fourni. Donnez ce dépôt à une IA de code (Claude Code, Codex,
  ou autre) et demandez-lui de le compiler pour votre Mac. Le fichier
  `notice-droit-verif-hallucination-ia.md` lui explique tout.
